## Findings

- E1: on 60 real OoC images x 11 corruptions x 5 severities, Zelos flags 97.1% of severity>=3 corruptions and names the injected cause for 31.0% of flagged images (top-2: 49.0%; chance 11.1%).
- E1: the pre-registered dev-session reference also flags 76.7% of clean test images (cross-session acquisition shift). A batch-relative reference (unsupervised, added after that result) lowers clean flags to 46.7% with AUROC 0.728 vs 0.778.
- E2: the expert good/bad label appears to track culture state rather than image artifacts: the artifact QC score reaches AUROC 0.393 while non-parametric kNN label transfer on the same physics features reaches 0.710 (best detector: knn_handcrafted_k15, n_test=301, session-grouped split).
- E4: over 48 open-access papers / 2379 chunks, the best retrieval mode is hybrid_rerank with paper-level MRR 1.000.
- E5: see results/e5.md for template vs ungated LLM vs gated LLM grounding rates.
