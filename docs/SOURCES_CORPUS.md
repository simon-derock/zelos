# Literature corpus sources

The evidence retriever searches a corpus of open-access organ-on-a-chip and microscopy-QC papers. This page is generated by `python scripts/build_corpus.py` (or `--docs-only`) from `corpus/manifest.csv`.

## How it was built

1. Europe PMC REST search (`resultType=core`, `OPEN_ACCESS:y AND HAS_FT:y`) for these queries: `"organ-on-a-chip" AND brightfield`; `"organ-on-a-chip" AND "image analysis"`; `"organ-on-a-chip" AND imaging`; `microfluidic cell culture AND bubble`; `"organ-on-a-chip" AND "machine learning"`; `microphysiological system AND imaging`; `brightfield microscopy AND "image quality"`; `autofocus microscopy cell culture`; `"flat-field" correction microscopy`; `cell seeding density microfluidic`; `"organ-on-a-chip" AND "quality control"`; `"organs-on-chips" AND microscopy`.
2. Only records whose reported license is CC BY or CC0 were kept (non-commercial, no-derivatives and share-alike licenses were excluded). The license string is stored per paper and per chunk.
3. Seed papers PMC11430660, PMC8879989 were included when their license qualified.
4. Full-text JATS XML was fetched from `/{PMCID}/fullTextXML`; abstract and body paragraphs were parsed with the Python standard library, non-content sections (acknowledgements, funding, conflicts, data availability, ...) were dropped, and the text was split into ~180-word chunks with 30-word overlap (`chunk_id = PMCID::s<section>::<j>`, chunks under 30 words dropped).
5. Downloaded text is treated as data only; the SHA-256 of each full-text XML is in the manifest.
